# 💳 Credit Card Fraud Detection System

Identify suspicious credit card transactions with machine learning and explore fraud
patterns through charts and an interactive web dashboard.

| | |
|---|---|
| **ML models** | Random Forest, Logistic Regression |
| **Data mining & visualization** | Fraud trends over time, by hour, by merchant, by fraud type, transaction charts |
| **Dashboard** | Streamlit web app: trends, model comparison, single-transaction check, CSV batch scoring |
| **Language** | Python 3.10+ (tested on Python 3.14) |
| **Difficulty** | Medium |

For the full explanation of the project (problem, dataset, algorithms, results, viva
questions), read **[PROJECT_EXPLANATION.md](PROJECT_EXPLANATION.md)**.

---

## 1. What you get

- **50,000 realistic credit card transactions** (2% fraud), generated by the project. You don't need to download anything.
- **15 report-ready charts** saved as PNG files in `reports/figures/`.
- **Two trained models** saved in `models/`, with accuracy, precision, recall, F1, ROC-AUC and PR-AUC.
- **An interactive dashboard** in your browser with 5 pages:
  1. **Overview**: headline numbers and the daily fraud trend.
  2. **Fraud Trends**: interactive charts with date, category and channel filters.
  3. **Model Performance**: comparison table, ROC/PR curves, confusion matrix and a threshold slider.
  4. **Check a Transaction**: type in a transaction and get the fraud probability with reasons.
  5. **Batch Prediction**: upload a CSV file, score every row and download the results.
- **A command-line predictor** (`predict.py`) for scoring CSV files without the dashboard.

## 3. Windows setup (step by step)

### Step 1: Install Python (one time only)

1. Open **https://www.python.org/downloads/** and download **Python 3.12, 3.13 or 3.14**
   (any version from 3.10 up works; the project was tested on 3.14).
2. Run the installer. **On the first screen tick ✅ "Add python.exe to PATH"**, then click
   **Install Now**.
3. Check that it worked. Open **Command Prompt** (press `Win` key, type `cmd`, press Enter)
   and run:

   ```bat
   python --version
   ```

   You should see something like `Python 3.13.x`.
   If you get *"Python was not found"*, see [Troubleshooting](#7-troubleshooting).

> **Optional:** install **[Visual Studio Code](https://code.visualstudio.com/)** to read and
> edit the code. You don't need it to run the project.

### Step 2: Put the project on your computer

Copy or unzip the `credit-card-fraud-detection` folder somewhere simple, for example:

```
C:\Projects\credit-card-fraud-detection
```

Avoid OneDrive-synced folders if you can. They can slow down the library installation.

### Step 3: Install the libraries and train the models

You can do this either way:

#### Option A: one click (easiest)

Double-click **`setup_windows.bat`** in the project folder. It will:

1. create a virtual environment (`venv` folder),
2. install all libraries from `requirements.txt` (3–5 minutes, needs internet),
3. generate the data, draw the charts and train both models (under a minute).

Wait for **"Setup complete!"** and you're done. Go to [section 4](#4-how-to-run).

#### Option B: manual commands (to see each step)

Open **Command Prompt** and run these one by one:

```bat
cd C:\Projects\credit-card-fraud-detection
```

Create a virtual environment, a private folder of libraries just for this project:

```bat
python -m venv venv
```

Activate it. Your prompt will start with `(venv)`:

```bat
venv\Scripts\activate
```

Upgrade pip and install the libraries:

```bat
python -m pip install --upgrade pip
```

```bat
pip install -r requirements.txt
```

Generate the dataset, create the charts and train the models:

```bat
python main.py
```

> **Using PowerShell instead of Command Prompt?** Activate with
> `.\venv\Scripts\Activate.ps1`. If PowerShell says *"running scripts is disabled on this
> system"*, run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` first. It only
> affects that one PowerShell window.

### Libraries that get installed

| Library | Used for |
|---|---|
| `numpy`, `pandas` | data generation and handling |
| `scikit-learn` | Random Forest, Logistic Regression, preprocessing, metrics |
| `joblib` | saving and loading trained models |
| `matplotlib`, `seaborn` | static charts in `reports/figures/` |
| `streamlit` | the web dashboard |
| `plotly` | interactive charts in the dashboard |

Nothing else is required: no database, no GPU, no Kaggle account.

## 4. How to run

> Every time you open a **new** Command Prompt, go to the project folder and activate the
> virtual environment first:
>
> ```bat
> cd C:\Projects\credit-card-fraud-detection
> venv\Scripts\activate
> ```
>
> (The `.bat` files do this for you.)

### 4.1 Start the dashboard

Double-click **`run_app.bat`**, or run:

```bat
streamlit run app.py
```

Your browser opens **http://localhost:8501** with the dashboard. If it doesn't open by itself,
type that address into your browser.

- The first time, Streamlit may ask for an **email** in the terminal. Just press **Enter**.
- Keep the black terminal window open while you use the dashboard.
- To stop the dashboard, click the terminal window and press **Ctrl + C**.

### 4.2 Re-run the pipeline (data → charts → models)

```bat
python main.py
```

Other options:

```bat
python main.py --step data
```

```bat
python main.py --step eda
```

```bat
python main.py --step train
```

```bat
python main.py --rows 100000 --fraud-rate 0.01
```

| Command | What it does |
|---|---|
| `python main.py` | runs everything (about 5 seconds) |
| `--step data` | only regenerates `data/transactions.csv` |
| `--step eda` | only redraws the fraud-trend charts |
| `--step train` | only retrains and re-evaluates the models |
| `--rows N --fraud-rate R` | changes the dataset size and the share of fraud |

### 4.3 Score a CSV file from the command line

```bat
python predict.py --input data\sample_transactions.csv
```

```bat
python predict.py --input data\sample_transactions.csv --model lr --threshold 0.3
```

- `--model rf` (Random Forest, default) or `--model lr` (Logistic Regression)
- `--threshold` sets the probability at which a transaction is flagged (default 0.5)
- Results are saved to `reports\predictions.csv`

Your own CSV needs these columns:
`timestamp, merchant_category, card_type, amount, customer_avg_amount, is_online,
is_international, distance_from_home_km, time_since_last_txn_min, txn_count_last_24h,
is_new_merchant, failed_attempts`. Open `data\sample_transactions.csv` for an example.

### 4.5 Share a live link anyone can open (free)

Google Drive can only share the files. To share the **running dashboard** as a website link
(for example `https://my-fraud-app.streamlit.app`), host it on **Streamlit Community Cloud**.
It is free and only needs a GitHub account.

1. **Put the project on GitHub**
   1. Sign in at https://github.com, click **New repository**, give it a name (for example
      `credit-card-fraud-detection`), choose **Public** and click **Create repository**.
   2. On the new repository page, click **uploading an existing file**.
   3. Unzip the project, open the `credit-card-fraud-detection` folder, select everything inside
      it (`app.py`, `main.py`, `requirements.txt`, the `src` folder, ...) and drag it onto the page.
      Do not upload a `venv` folder.
   4. Click **Commit changes**.
2. **Deploy it**
   1. Go to https://share.streamlit.io and sign in with **GitHub**.
   2. Click **Create app**, deploy from GitHub, and choose your repository, branch `main` and
      main file `app.py`. You can also pick your own App URL here.
   3. Optional: under **Advanced settings**, choose Python 3.12.
   4. Click **Deploy**. The first build installs the libraries and takes a few minutes.
3. **Share the link** of your app (`https://<your-app-name>.streamlit.app`).

A new server has no data yet, so the first visit shows *"First start: generating the data and
training the models"* for up to a minute, then the dashboard opens. Free apps go to sleep after
a while without visitors. The next visitor clicks the button to wake it up, and the first start
happens again.

## 7. Troubleshooting

| Problem | Fix |
|---|---|
| `'python' is not recognized` or *"Python was not found; run without arguments to install from the Microsoft Store"* | Python is not on PATH. Re-run the Python installer, choose **Modify**, and tick **"Add Python to environment variables"**. Or use `py` instead of `python` (e.g. `py -m venv venv`). Also turn off the Store shortcut: *Settings → Apps → Advanced app settings → App execution aliases*, switch off `python.exe` and `python3.exe`. |
| `pip install` fails with *"Could not find a version that satisfies the requirement"* | Your Python is too new or too old for the libraries. Install **Python 3.12 or 3.13** and repeat the setup (delete the `venv` folder first). |
| `pip install` fails with SSL / proxy / timeout errors | You are probably on a college or office network. Try another network or a mobile hotspot, or run `pip install -r requirements.txt --default-timeout=120`. |
| `'streamlit' is not recognized` | The virtual environment is not active. Run `venv\Scripts\activate` first, or use `python -m streamlit run app.py`. |
| PowerShell: *"running scripts is disabled on this system"* | Use Command Prompt, or run `Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass` in that PowerShell window. |
| Dashboard shows *"First start: generating the data and training the models"* | Normal when there is no data yet (for example on a new server). Wait up to a minute; it happens only once. |
| *"Port 8501 is already in use"* | Another dashboard is still running. Close it, or start on another port: `streamlit run app.py --server.port 8502`. |
| Browser doesn't open | Open **http://localhost:8501** yourself. |
| `ModuleNotFoundError: No module named 'src'` | Run the commands from the project folder (the one with `main.py`), not from inside `src`. |
| Model files fail to load after upgrading libraries | Retrain: `python main.py --step train`. |
| Windows Defender SmartScreen warns about the `.bat` file | Click **More info → Run anyway**, or run the commands from Option B by hand. |
